# スタログ

勉強中に2秒の動画を撮って、科目と勉強時間を一緒に記録する、スマホ用のWebサイトです。
1日(朝4時〜翌朝4時)の動画を時間順に続けて再生でき、グループの友達と1日を見せ合えます。

公開URL:https://yoshitarok.github.io/sutalog/

## できること

**撮る**
- 勉強タイマー(スタート → 終わったら「2秒撮る」で、その時間がそのまま記録される)
- 科目を選んで2秒撮る。勉強時間は1分〜5時間で自由に入れられる
- 1時間ごとのお知らせ(ページを開いている間だけ)

**じぶん**
- 1週間のふりかえり(7日間の棒グラフ・先週との比較・科目ごとの時間)
- 1日の動画を続けて再生。自分の動画だけ消せる(消す前に確認が出る)

**グループ**(1グループ20人まで、招待コード6文字で参加)
- みんなの1日を続けて再生、人ごとの勉強時間
- いま勉強中(タイマー中の人と、1時間以内に撮った人)
- 👏 ナイス(友達の動画に1タップで送る)
- みんなで目標(グループの1日の目標時間と進み具合)
- チャット(未読の数つき、開いている間はすぐ届く)

**ランキング**
- 全国勉強時間ランキング(今日・この1週間、上位50人と自分の順位)
- 参加した人だけが、ランキング用の名前で載る。1本の記録で数えるのは前に撮ってから実際にたった時間まで(ごまかし防止)

**大会**
- 運営が期間と景品を決めて開く全国大会。個人の部(ランキング参加者)とグループ対抗の部(運営が選んだグループ・合計時間)
- はじめての人向けの案内(初回ログイン時、ヘッダーの「使い方」から再表示)
- パスワードを忘れたときのメール再設定

**そのほか**
- メールアドレスとパスワードで登録。iPhoneのパスワード保存に対応、ログインしたままになる
- ホーム画面に追加できる(専用アイコン)。新しい版が出たら自動で読み直す
- Google などの検索には出さない設定(noindex)
- LINE などで送ったときの画像(`ogp2.png`)

## つくり

- `index.html` 1ファイルで完結(HTML / CSS / JavaScript)
- バックエンドは Supabase(ログイン・データベース・動画の保存・リアルタイム)
  - `index.html` に入っているのは公開用の鍵だけ。**secret / service_role の鍵は絶対にここに貼らない**
  - 誰が何を見られるかは Supabase の RLS(行ごとの決まり)で守っている
- GitHub Pages で公開(`main` ブランチ)

## Supabase の設定

機能を足したときに、Supabase の **SQL Editor** で実行した設定文です。
どれも何回実行しても大丈夫なように書いてあります。

| ファイル | 中身 |
|---|---|
| `supabase/2026-10-nice-goal.sql` | 👏 ナイス(`reactions` 表)と、みんなで目標(`groups.goal_minutes`、`set_group_goal`) |
| `supabase/2026-10-chat.sql` | チャット(`messages` 表とリアルタイム) |
| `supabase/2026-10-tournament.sql` | 大会(`tournaments`・`app_admins`・`groups.contest_opt_in`、`create_tournament` など)。ランキングの関数をログインした人だけに限る設定も含む |
| `supabase/2026-10-ranking.sql` | 全国ランキング(`profiles.rank_opt_in` / `rank_name`、`set_ranking` / `my_ranking` / `get_ranking`) |

実行のしかた:Supabase → 左のメニューの **SQL Editor** → **+ New** → ファイルの中身を全部貼る → **Run** →「Success」と出ればOK。

## 更新するときの決まり

- `index.html` を変えたら、中の `APP_VERSION` の値も変える(ホーム画面から開いた人のページが自動で新しくなる)
- `promo/sutalog_promo.mp4` は宣伝動画(縦長38秒)
